FAQ

What is KREW?

KREW is a Discord bot project designed for server management, moderation, utilities, automation and other server tools.

How do I add KREW?

Click the Add KREW button and follow Discord's authorization process.

Where can I get support?

Join the official KREW support server.

Is the dashboard live?

The public dashboard is initially a front-end preview. A real dashboard requires a backend and Discord OAuth2.

Are all commands listed?

The command page currently contains reference examples. It should eventually contain the confirmed live KREW command list.

Can I suggest a feature?

Use the support server for suggestions and project discussion.

Need help with KREW?

Use the support server for questions, bug reports, suggestions, bot problems, setup help, dashboard problems and general project discussion.
