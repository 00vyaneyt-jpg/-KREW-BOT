# KREW BOT Website

A simple static KREW Discord bot website.

## Files

- `index.html` — complete website, including HTML, CSS, JavaScript and animated line effects.
- `README.md` — setup instructions.

## GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`.
3. Upload `README.md`.
4. Open **Settings → Pages**.
5. Select the main branch and repository root (`/`).
6. Save.
7. Open the generated GitHub Pages URL.

## Important

The dashboard is a front-end preview. A real dashboard requires Discord OAuth2, a backend, a database, Discord API integration and server-side permission checks.

Do not place a Discord bot token in this repository or in public client-side code.
